# Sales Reporting Automation using Python

## Project Overview
This project automates sales data cleaning, KPI generation, and reporting using Python and Pandas.

## Features
- Automated data cleaning
- KPI calculations
- Revenue analysis
- Average Order Value (AOV)
- Product performance analysis
- Sales trend analysis

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains:
- Order IDs
- Customer IDs
- Product details
- Quantity
- Price
- Payment mode
- City-wise sales

## KPIs Generated
- Total Revenue
- Top Selling Products
- Average Order Value
- Sales by City
- Payment Method Distribution
